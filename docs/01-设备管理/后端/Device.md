# Device — 设备实体

对应数据库表 `iot_device`。

## 关键字段

| 字段 | 类型 | 说明 |
|------|------|------|
| deviceId | Long | 主键 |
| deviceName | String | 设备名称 |
| status | String | 设备状态：`ONLINE`(在线) / `OFFLINE`(离线) / `UNKNOWN`(未知) |
| deviceType | String | 设备类型 |
| ipAddress | String | IP地址 |
| responsible | String | 责任人 |
| responsiblePhone | String | 责任人电话（变更通知短信接收号码） |
| icon | String | 拓扑图标标识 |
| cableType | String | 线缆类型：fiber/ethernet/wireless/coaxial |
| parentId | Long | 父设备ID（拓扑层级关系） |

## 状态字段详解

`status` 字段取值为 String 枚举，不由前端表单提交，**完全由后端定时任务驱动更新**：

| 值 | 含义 | 触发条件 |
|----|------|---------|
| `ONLINE` | 在线 | `DeviceHeartbeatTask` ping 可达 |
| `OFFLINE` | 离线 | `DeviceHeartbeatTask` ping 不可达，或 AlertManager Webhook 告警 |
| `UNKNOWN` | 未知 | 默认初始值，未进行过心跳检测 |

状态变更时自动触发 `updateDeviceStatus()` 副作用链（见 DeviceServiceImpl 文档）。
