## 部门过滤机制

`selectDeviceList` 方法中，`deptId` 参数从 `Device.deptId`（继承自 BaseEntity）传入，XML 层通过 `find_in_set(ancestors)` 实现子部门递归过滤：

```sql
AND (d.dept_id = #{deptId} OR d.dept_id IN (
    SELECT t.dept_id FROM sys_dept t WHERE find_in_set(#{deptId}, ancestors)
))
```

同时 `selectDeviceList` 通过 `LEFT JOIN sys_dept sd ON d.dept_id = sd.dept_id` 获取 `sd.dept_name`，映射到 `Device.deptName` 用于前端展示。

## 注意事项

- **部门字段**：`deptId` 继承自 `BaseEntity`，`deptName` 为联表展示字段（不入库）
- **租户隔离**：`tenantId` 过滤由 `TenantScopeInterceptor` 自动追加，Mapper 层不显式处理
- **逻辑删除**：设备表未启用 `delFlag`，使用物理删除
