# 设备列表页

设备管理的列表页面，包含搜索区、统计卡片、设备表格、新增/修改弹窗。

## 设备状态渲染

设备状态**不使用若依字典翻译**，采用硬编码 `v-if` 判断：

| 状态值 | 标签样式 | 显示文本 |
|--------|---------|---------|
| `ONLINE` | `el-tag type="success"` 绿色 | 在线 |
| `OFFLINE` | `el-tag type="danger"` 红色 | 离线 |
| `UNKNOWN` | 默认灰色 | 未知 |

```html
<el-tag v-if="scope.row.status === 'ONLINE'" type="success">在线</el-tag>
<el-tag v-else-if="scope.row.status === 'OFFLINE'" type="danger">离线</el-tag>
```

## 关键功能

- **统计卡片**：页面顶部展示在线/离线/未知设备数量，通过 3 个独立 API 调用统计（`pageSize: 1` 仅取 total）
- **报修按钮**：仅离线设备（`status === 'OFFLINE'`）显示报修按钮
- **表单禁用 status**：新增/修改表单中 `delete this.form.status`，设备状态不由前端提交，完全由后端定时任务同步
- **搜索过滤**：状态下拉框支持按 ONLINE/OFFLINE 筛选

## 状态更新链路

```
DeviceHeartbeatTask (Quartz 每分钟)
  └→ deviceService.updateDeviceStatus()
      └→ DB iot_device.status 更新
          └→ 前端列表刷新时获取最新值
```
