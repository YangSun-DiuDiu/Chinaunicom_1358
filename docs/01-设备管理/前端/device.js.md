# device.js — 设备管理前端 API 模块

设备管理页面的所有后端 API 调用封装，统一使用框架 `request` 工具。

## API 列表

### 设备 CRUD

| 函数 | 方法 | URL | 说明 |
|------|------|-----|------|
| `listDevice(query)` | GET | `/device/list` | 分页查询设备列表，query 支持 deptId 部门过滤 |
| `getDevice(deviceId)` | GET | `/device/{deviceId}` | 查询设备详情 |
| `addDevice(data)` | POST | `/device` | 新增设备 |
| `updateDevice(data)` | PUT | `/device` | 修改设备（含 deptId 部门变更） |

| `exportDevice(query)` | POST | `/device/export` | 导出设备 Excel |

### 部门树

| 函数 | 方法 | URL | 说明 |
|------|------|-----|------|
| `deptTreeSelect()` | GET | `/device/deptTree` | 查询部门树结构（TreePanel + Treeselect 共用） |

export function deptTreeSelect() {
