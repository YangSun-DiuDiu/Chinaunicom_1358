# VisitorH5Controller

访客 H5 自助登记控制器，供访客通过手机端自行提交预约。**无需登录**。

**请求前缀**: `/visitor/h5`（公开路径）

## 接口列表

| 方法 | HTTP | 路径 | 权限 | 说明 |
|------|------|------|------|------|
| `submit` | POST | `/submit` | 无（公开） | 访客自主提交预约登记 |
| `hosts` | GET | `/hosts` | 无（公开） | 查询可选被访人列表 |

## 核心逻辑

### submit()
必填校验（visitorName / visitorPhone / hostName），委托 `registerWalkin()` 完成事务登记。返回 passCode + appointmentId + 完整 log 记录。

### hosts()
从已有预约记录中提取唯一被访人列表（hostName + hostDept + hostPhone 去重），供 H5 页面下拉选择。

## 依赖

- `IVisitorAppointmentService` — registerWalkin + selectAppointmentList
