## 核心逻辑

- **add()**: 自动生成 8 位通行码（UUID 截取），`createBy` 设置为当前用户，委托 `insertAppointment()` 完成被访人匹配 + 审批人通知
- **approve()**: 校验 appointmentId 和 status 非空后，委托 `approveAppointment()` 处理审批 + 创建来访记录 + 发送短信
- **cancel()**: 仅 PENDING / APPROVED 状态可取消
- **complete()**: 仅 VISITING / APPROVED 状态可完成，自动记录离场时间
