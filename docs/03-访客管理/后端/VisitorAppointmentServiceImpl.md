# VisitorAppointmentServiceImpl

访客预约核心业务逻辑实现，负责预约全生命周期管理：创建（含被访人强制匹配）、审批、取消、完成，以及与短信中台的集成。

## 职责

- 预约 CRUD（增删改查列表）
- 审批流程（通过/拒绝 → 创建来访记录 → 发送短信）
- 被访人-审批人强制匹配（hostName → sys_user → approverId + deptId）
- 通行码验证 + 到访确认
- 自助登记/现场登记（事务中创建预约 + 来访记录）
- 短信通知（通知审批人 / 通知访客通行码）

## 核心方法

### insertAppointment()
创建预约，自动设置 `status=PENDING`，调用 `assignApproverAndDept()` 强制匹配被访人为审批人，匹配失败抛异常拒绝创建。成功后 `notifyApprover()` 短信通知审批人。

### approveAppointment()（@Transactional）
审批主流程：
1. 校验预约存在且状态为 PENDING
2. 设置 status、approverId、approveTime、approveRemark
3. 审批通过后连锁：确保通行码 → 防重复创建来访记录 → 创建 visitor_log (APPOINTMENT) → 短信通知访客

### registerWalkin()（@Transactional）
自助/现场登记的事务方法：生成通行码 → 创建预约（复用被访人匹配）→ 同步创建来访记录 (WALKIN)。

### assignApproverAndDept()
被访人匹配链：
1. 按 loginName (user_name) 精确匹配 sys_user
2. loginName 未命中 → 按 nickName (nick_name) 匹配
3. 均失败 → `throw ServiceException("被访人『xxx』不存在，请检查姓名是否正确")`
4. 成功 → 设置 approverId + deptId（以被访人部门为准）

### checkInVisitor()
通行码验证通过后，将 APPROVED/PENDING → VISITING。

### cancelAppointment()
仅 PENDING/APPROVED 可取消 → CANCELLED。

### completeAppointment()
仅 VISITING/APPROVED 可完成 → COMPLETED，记录 leave_time。

## 状态常量

| 常量 | 值 | 说明 |
|------|-----|------|
| STATUS_PENDING | PENDING | 待审批 |
| STATUS_APPROVED | APPROVED | 已通过 |
| STATUS_REJECTED | REJECTED | 已拒绝 |
| STATUS_CANCELLED | CANCELLED | 已取消 |
| STATUS_VISITING | VISITING | 来访中 |
| STATUS_COMPLETED | COMPLETED | 已完成 |

## 短信集成

| 方法 | 业务码 | 接收人 |
|------|--------|--------|
| `notifyApprover()` | `visitor_pending_notify` | 被访人 |
| `sendApprovalSms()` | `visitor_approval` | 访客 |

短信使用 `SmsUtil.sendSms()` 模板驱动，失败时 `sms_sent="N"` 不阻断主流程。
