# VisitorAppointmentMapper

访客预约表数据访问接口，对应 `visitor_appointment` 表。

## 接口方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `selectAppointmentList` | VisitorAppointment | 条件分页查询（支持 visitorName/phone/status/hostName/approverId/时间范围） |
| `selectAppointmentById` | Long appointmentId | 主键查询 |
| `selectPendingList` | Long approverId | 待审批列表（PENDING 状态），可选按审批人过滤 |
| `insertAppointment` | VisitorAppointment | 新增，useGeneratedKeys 回填 appointmentId |
| `updateAppointment` | VisitorAppointment | 动态更新非空字段 |
| `deleteAppointmentById` | Long appointmentId | 逻辑删除（del_flag='1'） |
| `selectAppointmentByPassCode` | String passCode | 通行码查询 |
| `selectUserIdByNickName` | String nickName | 按昵称查 user_id（被访人匹配） |
| `selectUserByNickName` | String nickName | 按昵称查用户完整信息（userId + deptId + userName） |
