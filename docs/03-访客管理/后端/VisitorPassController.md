# VisitorPassController

访客通行码公开访问控制器，用于门岗验证访客身份。**无需登录**。

**请求前缀**: `/pass`（公开路径，不在安全拦截链内）

## 接口列表

| 方法 | HTTP | 路径 | 权限 | 说明 |
|------|------|------|------|------|
| `getPassInfo` | GET | `/{passCode}` | 无（公开） | 根据通行码获取访客通行信息 |

## 核心逻辑

```
GET /pass/{passCode}
   → 查 visitor_appointment → 命中: 返回信息 + checkInVisitor() → VISITING
   → 查 visitor_log → 命中: 返回信息
   → 均未命中: "通行码无效或已过期"
```

返回字段：passCode, visitorName, visitorPhone, visitorCompany, hostName, hostDept, visitTime/entryTime, status。

## 依赖

- `IVisitorAppointmentService` — 通行码查预约 + checkInVisitor
- `IVisitorLogService` — 通行码查记录
