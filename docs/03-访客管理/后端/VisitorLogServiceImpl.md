# VisitorLogServiceImpl

访客出入记录服务层实现，提供记录的查询、新增、更新操作。

## 核心方法

### selectLogList()
条件查询访客记录列表，支持按 visitorName、visitorPhone、hostName、registerType、通行码等条件过滤。安全过滤（host_name 精确匹配）通过 Controller 层传入 `params.securityHostName` 实现。

### selectLogById()
根据 logId 查询单条记录详情。

### insertLog()
新增访客出入记录（APPOINTMENT / WALKIN 类型），入参包含完整访客信息 + deptId 数据范围。

### updateLog()
记录访客离开：校验记录存在后设置 `exit_time = now()`。

### selectLogByPassCode()
门岗验证场景：根据通行码查询来访记录。

## 依赖

- `VisitorLogMapper` — 记录数据访问
