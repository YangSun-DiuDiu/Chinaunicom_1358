# ry-vue100-v15-visitor-refactor.sql

访客系统重构 SQL（v15），核心变更：表结构标准化、approver_id 引入、dept_id 数据范围隔离。

## 涉及的表

- `visitor_appointment` — 增加 approver_id、pass_code、sms_sent、sms_content、dept_id 等字段
- `visitor_log` — 增加 pass_code、dept_id 等字段

## 关键变更

1. **approver_id**: 新增审批人字段，实现被访人=审批人绑定，支撑用户级数据隔离
2. **dept_id**: 新增部门ID字段，对接 DeptScopeInterceptor 部门级租户隔离
3. **pass_code**: 8位通行码，用于门岗扫码验证
4. **sms_sent / sms_content**: 短信发送状态和内容记录
5. **register_type**: 区分预约来访(APPOINTMENT)和现场登记(WALKIN)
