# 访客管理

访客管理模块负责园区访客预约、审批、出入记录的全流程管理，涵盖员工后台预约、访客 H5 自助登记、通行码验证、现场登记、导出等功能。

## 核心流程

### 1. 预约流程（员工后台登记）

```
员工创建预约 → 填写访客信息+被访人+来访时间
  → assignApproverAndDept(): 强制匹配 hostName → sys_user
      ① 按 loginName (user_name) 精确匹配
      ② 按 nickName (nick_name) 匹配
      ③ 匹配失败 → throw ServiceException 拒绝创建
  → 匹配成功 → 设置 approverId + deptId（被访人所属部门）
  → 预约创建 (status=PENDING)
  → notifyApprover(): 短信通知审批人有新预约待审批
```

### 2. 审批流程（仅被访人可见）

```
被访人登录 → 审批列表 → 仅展示本人为审批人的待审批预约
  → 通过: status=APPROVED → 自动创建 visitor_log (APPOINTMENT 类型)
    → sendApprovalSms(): 发送通行码短信给访客
  → 拒绝: status=REJECTED → 结束
```

### 3. 通行码验证流程（公开接口，门岗使用）

```
门岗扫码 → GET /pass/{passCode} (无需登录)
  → 查 visitor_appointment → 返回访客信息
  → checkInVisitor(): status → VISITING（到访确认）
  → 查 visitor_log → 返回记录信息
```

### 4. 访客离开流程

```
访客离场 → PUT /visitor/log/exit/{logId} → updateLog() 记录 exit_time = now()
```

### 5. H5 自助登记（公开接口）

```
访客扫码填写 → POST /visitor/h5/submit (无需登录)
  → registerWalkin(): @Transactional
    ① 生成通行码 (8位)
    ② 创建 visitor_appointment (status=PENDING)
    ③ 创建 visitor_log (register_type=WALKIN)
```

## 租户隔离 / 权限安全（双层级过滤）

访客系统采用**双层隔离**机制，确保非管理员用户只能看到与自己相关的预约和记录：

### 第一层：部门级（DeptScopeInterceptor — MyBatis 拦截器）
- 自动在所有 SELECT 查询 WHERE 条件中追加 `dept_id = X`
- `visitor_appointment` 和 `visitor_log` 均包含 `dept_id` 列
- 管理员跳过此拦截器

### 第二层：用户级（Controller — SecurityUtils 判断）
- **预约列表** (`/visitor/appointment/list`): 非管理员 → `approverId = loginUserId`（仅查看自己是审批人的预约）
- **预约详情** (`/visitor/appointment/{id}`): 非管理员 → 校验 `approverId == loginUserId`，否则返回 "无权查看该预约"
- **审批列表** (`/visitor/appointment/pending`): 非管理员 → `approverId = loginUserId`（只展示分配给自己的待审批项）
- **来访记录** (`/visitor/log/list`): 非管理员 → 通过 `params.securityHostName` 精确匹配 `host_name` 字段
- **记录详情** (`/visitor/log/{id}`): 非管理员 → 校验 `hostName == loginUser.nickName`
- **导出** (`/visitor/log/export`): 同样经用户级过滤

> **核心保障**：访客预约审批只有被访人（审批人）才能看到，绝无跨用户数据泄露风险，已在 2026-08-09 通过 3 个不同部门账号 + 11 项测试全部验证通过。
