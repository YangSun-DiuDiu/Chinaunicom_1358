# 访客出入记录页面

访客出入记录查询与管理页面，支持搜索、导出、离开记录。

## 页面功能

- **搜索区**: 按访客姓名、登记类型（预约来访/现场登记）、来访时间范围筛选
- **表格列**: 通行码、访客姓名/电话/单位、来访事由、被访人、被访部门、入场时间、离场时间、登记类型
- **操作按钮**: 导出
- **离开记录**: 记录访客离场时间

## 数据安全

非管理员自动过滤 `host_name`，仅展示自己是被访人的记录。详见后端 [VisitorLogController](../后端/VisitorLogController.md)。

## API 调用

参见 [visitor.js](../visitor.js.md) 中的 `listVisitorLog`、`getVisitorLog`、`registerVisitor`、`visitorExit`、`exportVisitorLog` 方法。
