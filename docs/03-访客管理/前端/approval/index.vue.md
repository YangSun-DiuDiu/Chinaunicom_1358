# 访客审批页面

被访人（审批人）专用审批页面，展示待审批的访客预约列表，支持通过/拒绝操作。

## 页面功能

- **表格列**: 通行码、访客姓名/电话/单位、来访事由、被访人、被访部门、来访时间、创建时间
- **操作按钮**: 通过、拒绝（弹窗输入审批备注）
- **刷新按钮**: 手动刷新列表

## 数据安全

待审批列表仅展示 `approverId = 当前用户ID` 的记录（后端 [VisitorAppointmentController.pending()](../后端/VisitorAppointmentController.md) 过滤）。被访人登录后只能看到分配给自己的待审批预约。

## 审批流程

通过 → `approveAppointment({appointmentId, status: 'APPROVED', approveRemark})` → 后端创建来访记录 + 发送通行码短信
拒绝 → `approveAppointment({appointmentId, status: 'REJECTED', approveRemark})`

## API 调用

参见 [visitor.js](../visitor.js.md) 中的 `pendingAppointment`、`approveAppointment` 方法。
