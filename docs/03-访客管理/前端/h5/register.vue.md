# 访客 H5 自助登记页面

访客手机端自助登记页面，无需登录，公开访问。

## 页面功能

- **登记表单**: 访客姓名、电话、身份证号、单位、来访事由、被访人选择（下拉从已有预约获取）
- **被访人选择**: 调用 `GET /visitor/h5/hosts` 获取可选被访人列表
- **提交**: 调用 `POST /visitor/h5/submit` 提交登记
- **通行码展示**: 提交成功后展示通行码供门岗验证

## 数据安全

此页面为公开页面，无需登录即可访问。提交的预约会通过 `assignApproverAndDept()` 强制匹配被访人，匹配失败拒绝创建。

## API 调用

提交：POST `/visitor/h5/submit`（公开接口，无需 token）
被访人列表：GET `/visitor/h5/hosts`（公开接口，无需 token）
