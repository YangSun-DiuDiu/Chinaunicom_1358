# 访客预约管理页面

访客预约列表与管理页面，支持预约的增删改查、审批、导出等全功能。

## 页面功能

- **搜索区**: 按访客姓名、电话、状态（PENDING/APPROVED/REJECTED/CANCELLED/VISITING/COMPLETED）、来访时间范围筛选
- **表格列**: 通行码、访客姓名/电话/单位、来访事由、被访人、被访部门、来访时间、状态、创建时间
- **操作按钮**: 新增、修改、删除、通过、拒绝、详情、取消、完成、导出
- **弹窗**: 新增/修改预约表单弹窗，审批通过/拒绝弹窗

## 权限控制

按钮级权限使用 `v-hasPermi`：
- `visitor:appointment:add` — 新增
- `visitor:appointment:edit` — 修改
- `visitor:appointment:remove` — 删除
- `visitor:appointment:export` — 导出

## 数据安全

非管理员自动过滤 `approverId`，仅展示自己是审批人的预约。详见后端 [VisitorAppointmentController](../后端/VisitorAppointmentController.md)。

## API 调用

参见 [visitor.js](../visitor.js.md) 中的 `listAppointment`、`addAppointment`、`updateAppointment`、`delAppointment`、`approveAppointment`、`cancelAppointment`、`completeAppointment` 方法。
