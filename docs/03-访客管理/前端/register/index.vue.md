# 现场登记页面

员工前台现场登记页面，用于门岗管理员为访客进行现场登记（WALKIN 类型）。

## 页面功能

- **登记表单**: 访客姓名、电话、身份证号、单位、来访事由、被访人、被访部门、是否有车/物品等
- **自动生成通行码**: 提交后返回 8 位通行码
- **同步创建记录**: 同时创建预约(PENDING) + 来访记录(WALKIN)

## API 调用

参见 [visitor.js](../visitor.js.md) 中的 `registerVisitor` 方法（POST `/visitor/log`）。
