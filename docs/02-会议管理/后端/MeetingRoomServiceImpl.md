# MeetingRoomServiceImpl — 会议室服务实现

会议室 CRUD 服务层实现，标准若依薄服务（直接透传 Mapper，无额外业务逻辑）。

## 职责

- 会议室列表查询（含部门过滤参数透传）
- 会议室单条详情 / 新增 / 修改 / 批量删除
