# MeetingRoomController — 会议室管理接口

会议室资源管理接口：CRUD + 组织架构部门树 + 门牌无鉴权列表。

## 接口列表

| 方法 | HTTP | 路径 | 权限 | 说明 |
|------|------|------|------|------|
| `list` | GET | `/meeting/room/list` | `meeting:room:list` | 分页查询会议室（含 deptId 部门过滤） |
| `deptTree` | GET | `/meeting/room/deptTree` | `meeting:room:list` | 组织架构部门树（与 sys_dept 同步） |
| `simpleList` | GET | `/meeting/room/simpleList` | 无 | 简单列表（门牌平板配置页，无鉴权） |
| `getInfo` | GET | `/meeting/room/{roomId}` | `meeting:room:query` | 单条详情 |
| `add` | POST | `/meeting/room` | `meeting:room:add` | 新增（dept_id 由 DeptFillAspect 自动填充） |
| `edit` | PUT | `/meeting/room` | `meeting:room:edit` | 修改（**不改** dept_id，归属创建时决定） |
| `remove` | DELETE | `/meeting/room/{roomIds}` | `meeting:room:remove` | 批量删除 |

## 核心方法

### deptTree(SysDept dept)

组织架构部门树，数据与系统管理-部门管理实时同步。

- 直接调 `ISysDeptService.selectDeptTreeList(dept)`，返回 id/label/children 结构（供前端 TreePanel 渲染）。
- 权限与列表一致（`meeting:room:list`），无需新增权限字符/菜单。
- 非管理员按数据权限返回本部门及子部门子树。

```java
@PreAuthorize("@ss.hasPermi('meeting:room:list')")
@GetMapping("/deptTree")
public AjaxResult deptTree(SysDept dept) {
    return success(deptService.selectDeptTreeList(dept));
}
```

### simpleList()

门牌平板配置页下拉用，**无需登录**（SecurityConfig 放行 + 无 @PreAuthorize）。拦截器在无登录态时 `getCurrentDeptId()` 抛异常 → 被 catch 跳过 dept 过滤，返回全量简单列表（roomId/roomName/location）。

### add / edit

- `add`：`@Validated` 校验必填（roomName/location/capacity），`createBy` 手动设置；`deptId` 由前端不传 → **DeptFillAspect** 注入当前用户/切换上下文部门。
- `edit`：`updateMeetingRoom` SQL **不含 dept_id**，编辑不改变会议室所属部门（防止编辑时 `deptId=null` 被 DeptFillAspect 误改为当前用户部门）。

## 依赖

- `IMeetingRoomService` — 会议室 CRUD 业务
- `ISysDeptService` — 部门树查询（组织架构）
- `BaseController` — 分页 `startPage()` / 统一返回 `getDataTable`、`success`、`toAjax`

## 注意事项

- 列表查询非管理员被 DeptScopeInterceptor 强制追加 `(dept_id = X OR dept_id IN (SELECT t.dept_id FROM sys_dept t WHERE find_in_set(X, t.ancestors)))`，管理员豁免。
- `deptTree` 与 `list` 共用权限 `meeting:room:list`，未新增菜单。
