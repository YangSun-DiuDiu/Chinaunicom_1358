# 会议室管理页 (room/index.vue)

会议室资源管理页面，布局对齐设备管理「设备列表」：**左侧组织架构树 + 右侧查询/表格**。

## 页面功能

- 左侧 **组织架构树**（TreePanel 组件），与系统管理-部门管理（sys_dept）实时同步
- 点击部门节点 → 按**本部门 + 全部子部门**过滤会议室
- 会议室表格：名称 / 位置 / 容量 / 设备 / **所属部门** / 状态 / 创建时间 / 平板地址
- 搜索（会议室名称、状态）+ 重置（清空过滤 + 取消树选中）
- 新增 / 修改 / 删除 + 平板地址复制
- 新增/编辑表单**无部门下拉**，部门由后端自动归属

## 关键功能

### 组织架构树侧边栏

```html
<tree-panel title="组织架构" :tree-data="deptOptions" search-placeholder="请输入部门名称"
            storage-key="meeting-room-dept-sidebar-width" :defaultExpandAll="true"
            @node-click="handleDeptNodeClick" @refresh="getDeptTree" ref="deptTreeRef" />
```

- 树数据 `deptOptions` 来自 `deptTreeSelect()`（GET /meeting/room/deptTree），id/label/children 结构。
- `created()` 进入页面同时拉列表 + 树。
- 点击节点 `handleDeptNodeClick(data)` → `query.deptId = data.id` → `getList()`。
- 重置 `resetQuery()` → 清空 query + `this.$refs.deptTreeRef.setCurrentKey(null)` 取消树选中。

### 所属部门列

表格新增列，展示 LEFT JOIN 关联出的部门名：

```html
<el-table-column label="所属部门" prop="deptName" min-width="120" :show-overflow-tooltip="true"/>
```

### 新增自动归属

表单无部门字段，新增时后端 `DeptFillAspect` 自动注入当前用户/切换上下文部门；编辑不改变归属。

### 平板地址复制

```js
copyBoardUrl(row) {
  const url = 'http://1.94.26.126:80/meeting/board?roomId=' + row.roomId
  navigator.clipboard.writeText(url).then(() => this.$message.success('已复制'))
}
```

## 数据流

```
created → getDeptTree()  → GET /meeting/room/deptTree → deptOptions
        → getList()      → GET /meeting/room/list (params: pageNum/pageSize/roomName/status/deptId)
点击树节点 → query.deptId → getList()（后端 find_in_set 含子部门）
新增 submit → POST /meeting/room（dept_id 前端不传，后端自动填充）
```

## ⚠️ 易踩坑（重要）

使用 `TreePanel` 组件**必须局部注册**：

```js
components: { TreePanel },
```

否则 Vue 把 `<tree-panel>` 当未知自定义元素渲染为空标签：树不显示（只剩「组织架构」标题），且 `resetQuery` 中 `this.$refs.deptTreeRef.setCurrentKey(null)` 报 `setCurrentKey is not a function`（$refs 拿到的是空 DOM 元素而非组件实例）。**2026-08-23 已修复**。
