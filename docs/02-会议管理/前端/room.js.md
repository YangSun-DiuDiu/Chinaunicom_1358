# room.js — 会议室 API 模块

会议室管理页全部接口封装，统一使用框架 `request`。

## API 清单

| 函数 | 方法 | 路径 | 说明 |
|------|------|------|------|
| `getList(query)` | GET | `/meeting/room/list` | 分页查询（支持 deptId 部门过滤） |
| `getRoom(roomId)` | GET | `/meeting/room/{roomId}` | 单条详情 |
| `addRoom(data)` | POST | `/meeting/room` | 新增（dept_id 后端自动填充） |
| `updateRoom(data)` | PUT | `/meeting/room` | 修改（不改部门归属） |
| `delRoom(roomIds)` | DELETE | `/meeting/room/{roomIds}` | 删除 / 批量删除 |
| `deptTreeSelect()` | GET | `/meeting/room/deptTree` | **组织架构部门树**（2026-08-23 新增） |

## deptTreeSelect（组织架构树）

```js
// 部门树（组织架构，与系统管理-部门管理数据同步）
export function deptTreeSelect() {
  return request({
    url: '/meeting/room/deptTree',
    method: 'get'
  })
}
```

返回 id/label/children 结构，供页面左侧 `TreePanel` 渲染；点击节点把 `data.id` 写入 `query.deptId` 触发列表过滤。
