## 部门隔离说明（2026-08-23）

- `meeting_room` 已移出 `DeptScopeInterceptor` 白名单：非管理员列表查询被强制追加 `(dept_id = X OR dept_id IN (SELECT dept_id FROM sys_dept WHERE find_in_set(X, ancestors)))`，即**本部门 + 全部子部门**。
- `dept_id` 由 `DeptFillAspect` 在创建时自动填充（当前用户/切换上下文部门），**前端表单不提供部门字段**。
- **存量数据要求**：历史 `dept_id IS NULL` 的会议室需先按创建人部门批量回填，否则对非管理员不可见（本项目 3 室已全部填充，回填 no-op）。
- 回填示例：
  ```sql
  UPDATE meeting_room r
  LEFT JOIN sys_user u ON u.user_name = r.create_by
  SET r.dept_id = u.dept_id
  WHERE r.dept_id IS NULL AND u.dept_id IS NOT NULL;
  ```
