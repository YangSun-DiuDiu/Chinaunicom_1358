# 会议管理

## 模块概述

会议管理模块覆盖园区会议室**资源管理 → 预约 → 审批 → 会议执行 → 门牌展示**全链路，包含 4 个管理页面 + 1 个独立门牌展示页：

| 页面 | 路径 | 功能 |
|------|------|------|
| 会议室管理 | `meeting/room` | 会议室资源 CRUD + **左侧组织架构树** + 部门数据隔离 |
| 会议预约 | `meeting/booking` | 会议室预约申请（选会议室/时间/参会人数） |
| 会议审批 | `meeting/approval` | 预约审批流（PENDING → APPROVED/REJECTED） |
| 会议管理 | `meeting/manage` | 已批准会议的执行管理（开始/结束/取消） |
| 会议室门牌 | `meeting/board`（独立页） | 会议门牌平板展示，`simpleList` 无鉴权接口供 Android WebView 调用 |

## 组织架构树 + 部门数据隔离（2026-08-23 新增）

会议室管理页对齐设备管理「设备列表」模式，新增**左侧组织架构树**，与系统管理-部门管理（`sys_dept`）实时同步：

- **树数据来源**：`GET /meeting/room/deptTree`（权限 `meeting:room:list`），内部调 `ISysDeptService.selectDeptTreeList`，返回 id/label/children 结构。
- **点击过滤**：点击部门节点 → 前端 `query.deptId` → 后端 SQL 追加 `(mr.dept_id = #{deptId} OR mr.dept_id IN (SELECT t.dept_id FROM sys_dept t WHERE find_in_set(#{deptId}, t.ancestors)))`，即 **本部门 + 全部子部门**（`find_in_set` 依赖 `sys_dept.ancestors` 冗余字段）。
- **所属部门列**：列表 SQL `LEFT JOIN sys_dept sd` 取 `dept_name`，表格新增「所属部门」列展示。
- **部门隔离**：`meeting_room` 已移出 `DeptScopeInterceptor` 白名单，**非管理员仅见本部门 + 子部门会议室**（与设备管理一致），管理员不受限。
- **自动归属**：新增/编辑表单**无部门下拉**，`dept_id` 由 `DeptFillAspect` 自动填充（当前用户所属部门或「选择组织」切换的上下文部门）；**归属在创建时决定，编辑不可改**（update SQL 不含 dept_id，防止编辑时被误改）。
- **存量数据**：历史会议室 `dept_id IS NULL` 的需先按创建人部门批量回填，否则对非管理员不可见（本项目 3 室已全部填充）。

**添加过程（从零到上线）**：
1. 后端 `MeetingRoomController` 新增 `/deptTree` 接口（注入 `ISysDeptService`）。
2. `MeetingRoomMapper.xml`：列表 SQL 主表加别名 `mr` + `LEFT JOIN sys_dept sd`；resultMap 加 `deptName`；select 加 `deptId` 过滤条件；`updateMeetingRoom` **不加** dept_id。
3. `MeetingRoom` 实体新增 `deptName`（查询关联、不落库）。
4. `DeptScopeInterceptor` 白名单移除 `meeting_room`。
5. 前端 `api/meeting/room.js` 新增 `deptTreeSelect()`；`views/meeting/room/index.vue` 引入 `TreePanel` 侧边栏 + `query.deptId` 过滤 + 「所属部门」列 + `resetQuery` 清树选中。
6. 存量数据回填 SQL → 前后端全量部署 → 端到端验证。

**⚠️ 易踩坑**：前端使用 `TreePanel` 必须 **`components: { TreePanel }` 局部注册**，否则 Vue 把 `<tree-panel>` 当未知自定义元素渲染为空标签（树不显示，且 `resetQuery` 里 `$refs.deptTreeRef.setCurrentKey` 报错）。

## 核心流程

```
用户发起预约(meeting_booking PENDING)
    → 审批人审批(APPROVED / REJECTED)
    → 会议管理页执行(开始/结束/取消)
    → 门牌平板展示当前/即将开始的会议(meeting/board)
```
