# 文档中心模块 — 设计规格说明书

**日期**: 2026-08-09
**状态**: 设计已确认，待实施
**版本**: v1.0

## 一、需求概述

在智慧园区管理系统中新增「文档中心」模块。系统每个功能模块的实现细节（后端接口、前端页面、数据库表结构、核心业务逻辑、模块间依赖）以结构化文档形式呈现。文档内容以 Git 管理 Markdown 文件存储，系统自动扫描代码包结构生成章节骨架并持续同步，开发者通过 Web 页面浏览和编辑。

### 核心目标

1. 为所有业务模块提供细粒度技术文档（Controller → Service → Mapper → Entity → 前端页面 → 数据库表）
2. 文档目录结构与代码包结构自动化映射同步
3. 文档内容以 Git 仓库 Markdown 文件存储，天然带版本历史
4. 文档中心免登录访问（白名单）
5. 提供优秀的阅读体验——区别于管理后台的视觉设计

## 二、5 个核心决策

| # | 决策项 | 选择 |
|---|--------|------|
| 1 | 内容来源 | B — 半自动：系统扫包生成 `.md` 骨架（含 frontmatter + 接口/方法清单），开发者填充正文 |

| 5 | 关联方式 | A — 约定式映射：源码路径与 docs 目录按命名约定自动对应 |

### 3.4 同步行为矩阵

| 场景 | 行为 |
|------|------|
| 新增源码文件 | 在对应 docs 目录生成 `.md` 骨架，`autoGenerated: true` |
| 源码文件删除 | `.md` 文件 frontmatter 标记 `orphaned: true`，正文顶部追加 `> ⚠ 关联源码已删除` 引用块 |
| 源码文件移动 | 旧位置标记 `orphaned: true` + ⚠ 标记，新位置生成新骨架（正文不迁移） |
| 源码文件修改 | 更新 frontmatter 的 `sourceHash` 和 `updatedAt`，正文不受影响 |
| 人工编辑 .md | 重新扫描时 `autoGenerated` 改为 `false`，不再更新骨架内容 |
| 新增模块 | 在 `module-order.yml` 自动追加，在 `docs/` 生成完整目录树 |

## 四、持续同步机制

### 4.1 触发方式

采用 **Quartz 定时轮询** 方案，每 60 秒检查一次 `HEAD` commit hash：

```
Quartz: DocSyncTask.checkAndSync()  每分钟
  → 比较当前 HEAD hash 与上次同步记录的 hash
  → 不同则调用 DocSyncService.syncAll()
  → 记录本次 hash，写入 sys_config 表
```

### 4.2 同步流程

```
DocSyncService.syncAll()
  ├─ 1. 扫描 controller 子目录 → 识别业务模块列表
  ├─ 2. 读取 docs/module-order.yml → 获取排序
  ├─ 3. 逐模块扫描：
  │     ├─ 扫描后端源码（controller/service/mapper/domain/mapper XML）
  │     ├─ 扫描前端源码（views/api）
  │     ├─ 扫描数据库 SQL
  │     └─ 与 docs/ 目录对比 → 执行新增/标记过时
  └─ 4. 记录同步日志（时间、新增文件数、过时文件数）
```

### 4.3 手动触发

提供 `POST /doc/sync` 接口作为补充，需要 `doc:sync` 权限。前端页面底部状态栏也提供「立即同步」入口。

### 6.4 DocTree 组件

- 基于后端 `/doc/tree` 接口返回的 JSON 树渲染
- 文件夹用 `▶`/`▼` 图标展开折叠
- 文件用 `📄` 图标
- 骨架文件（`autoGenerated: true`）：**灰色斜体**标题
- 过时文件（`orphaned: true`）：**⚠ 黄色标记**
- 当前选中文件**高亮 + 左侧书脊线**
- 顶部搜索框：输入关键词过滤节点，实时匹配
- 每个模块节点右侧显示**填充进度**：`12/18` 表示 18 个文件中 12 个已编写

### 6.5 DocReader 组件

- 使用 `marked` 解析 Markdown → HTML
- 使用 `highlight.js` 代码高亮（Java / Vue / SQL / XML / JS / YAML）
- 支持表格、引用块、图片、Mermaid 图表
- frontmatter 元数据在底部信息栏展示（不渲染到正文）：
  - 📎 关联源码路径（点击可跳转）
  - 🏷 文件类型标签（Controller / Service / Entity / Vue / SQL）
  - 🕐 最后同步时间
- 未填充文档显示**空状态提示**："此文档尚未编写实现说明"
- 正文区最大宽度 `780px` 居中，左右留白保证阅读舒适

### 6.6 状态栏（底部固定）

```
左: 文档版本 a3f8372    中: 8个模块 · 127个文档 · 15个待填充    右: 2分钟前同步 · [立即同步]
```

## 八、匿名访问白名单

文档中心路由标记 `noAuth: true`，需要在以下位置配置白名单放行：

### 8.1 前端路由守卫

`ruoyi-ui/src/permission.js` — 在 `router.beforeEach` 中检查 `to.matched.some(r => r.meta.noAuth)`，匹配则直接放行，跳过 token 校验。

### 8.2 后端 Security 配置

`SecurityConfig.java` — 在 `configure(HttpSecurity)` 中的匿名访问列表增加 `/doc/tree`, `/doc/content`, `/doc/status`, `/doc/search`。

### 8.3 菜单显示

文档中心菜单在 `sys_menu` 表中配置 `visible=0` 但在前端路由中显式声明 `hidden: false`，确保未登录用户也能看到入口。后端菜单加载接口不过滤该路由。

## 十一、风险与边界

1. **大仓扫描性能**：首次全量扫描约 100-200 个文件，预计耗时 <2 秒，每分钟轮询仅比较 hash，不重复扫描
2. **文件编码**：`.md` 文件统一 UTF-8，读取时显式指定编码
3. **路径安全**：`/doc/content?path=xx` 接口校验 path 不包含 `..` 防止目录穿越
4. **高并发**：文档内容接口返回静态文件内容，可配合 Nginx 缓存
5. **Git 不可用时降级**：若 `.git` 目录不可访问，同步任务跳过，返回上次成功同步状态
