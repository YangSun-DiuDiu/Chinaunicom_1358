# 设备管理与智能化管理功能说明

## 一、设备台账与基础运维

1. **设备全生命周期管理**：集中管理园区所有设备的档案信息，支持按名称、类型（网络设备/监控设备/NVR 等）、状态（在线/离线/未知）多维度筛选，提供新增、修改、删除、Excel 导入导出能力。
2. **设备配件管理**：维护备品备件的库存台账，记录配件编码、型号、单位、单价，库存低于预警阈值时自动红色标记，并关联维修工单追踪配件使用消耗。
3. **设备端口管理**：按设备维度查看和管理网络端口列表，记录端口名称、类型、速率及 up/down 状态。

## 二、实时监控与拓扑可视化

4. **设备心跳巡检**：定时任务周期性 Ping 检测全网设备在线状态，记录每次检测的延迟和成败结果，统计成功率，支持按日期范围和结果筛选导出。
5. **网络拓扑图**：以递归树形组件可视化展示设备间物理连接关系，支持缩放操作，节点着色实时反映在线/离线/未知状态，点击节点查看设备详情弹窗。
6. **SNMP 深度采集**：内置系统 snmpwalk + Java 原生 SNMP 双引擎，支持端口监控（名称/速率/上下行状态）、MIB 浏览器（预设常用 OID + 自定义 GET/Walk）、Prometheus 实时指标查询、TOML 配置文件远程部署，NVR 设备专属存储使用率查看。
7. **Grafana 监控集成**：每台设备绑定 Grafana 监控面板深度链接，从设备列表一键跳转查看 CPU、内存、流量等 Prometheus 时序图表；SNMP 页面内嵌 Grafana 驾驶舱 iframe。

## 三、告警与故障处理

8. **AlertManager 告警接入**：对接 Prometheus + AlertManager 告警链路，通过 Webhook 接收设备离线/故障告警，自动解析告警标签匹配台账设备，实时更新设备在线状态并生成故障记录。
9. **故障预警看板**：实时展示当前离线设备列表（含位置、负责人、联系电话），追踪状态变更历史（变更前后状态、时间、短信通知状态），支持一键报修触发工单流程。
10. **多通道短信通知**：设备离线自动发送离线告警短信，手动报修发送报修通知，工单转派发送转派通知，设备恢复上线发送上线通知，全链路短信模板化、可追溯、失败自动标记。

## 四、维修工单体系

11. **工单全流程管理**：支持手动创建和告警自动转工单，工单状态流转（待处理 → 已派发 → 已接收/已拒绝 → 已完成），支持转派操作并自动短信通知接单人，工单编号自动生成。
12. **维修人员工作量统计**：按维护人员维度展示工单统计（总数/已完成/进行中/拒绝），完成率进度条着色（≥80% 绿 / ≥50% 橙 / <50% 红）。
13. **免登录维修确认**：维修人员通过短信中的 Token 链接打开公开确认页面（无需登录），查看工单信息、上传维修前后照片、选择配件消耗、提交维修完成。

## 五、智能化通行管理

14. **人员通行设备管理**：管理园区闸机、门禁控制器等通行设备，支持海康威视/大华等多品牌选型，提供一键批量连通性检测（TCP 连通、延迟、SDK 类型、HTTP 接口可达性、开发建议），离线设备支持报修。
15. **车辆通行设备管理**：管理车牌识别相机、道闸等车辆通行设备，功能与人员通行设备一致，统一品牌选型和检测体系。
16. **通行权限管理**：管理人员和车辆的通行权限记录，支持查询、新增、修改、删除，关联通行设备实现权限下发。
17. **人员车辆绑定**：维护人员与车辆的一对一或一对多绑定关系。

## 六、视频监控管理

18. **监控设备管理**：管理园区 NVR/DVR/IPC 等视频监控设备，配置 RTSP 地址、端口、账号密码、安装位置，支持一键连通检测、单设备在线测试和视频预览跳转。
19. **视频实时预览**：设备树可搜索过滤（在线状态色标），右侧播放区支持实时流和快照模式，提供播放/暂停控制和抓图功能。
20. **电子地图模式**：上传园区室内外平面图作为底图，在底图上标记监控设备安装位置，支持底图类型筛选（室外/室内）、名称搜索，实现空间化设备管理。
21. **底图管理**：独立维护电子地图底图素材，记录底图名称、尺寸（宽×高）、所属建筑楼层，支持图片预览和搜索。

## 七、数据分析与 AI 报告

22. **网络健康报告**：对接 Prometheus 聚合全网设备指标（在线率、端口 up 率、设备数、故障数、丢包率、带宽超限比、流量抖动），通过三维加权评分算法（可用性 × 响应延迟 × 流量健康度）生成综合健康评级，支持日/周/月/季/半年/年六个周期查询。
23. **AI 智能运维分析**：集成 DeepSeek 大模型，对聚合监控数据进行自然语言分析，自动输出 B 级分级评估报告（健康评级 + 三维分项得分 + 风险提示 + 优化建议），网络不可达时自动降级兜底。
